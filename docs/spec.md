# 나날 기능 명세서

나날의 현재 동작 기준 문서다. 앱의 동작·문구·데이터 규칙이 바뀌면 같은 작업 안에서 이 문서도 고친다.

- 기준일: 2026-10-19
- 함께 고치는 문서: [나날 기능 명세서 (Claude Docs)](https://claude.ai/code/artifact/71a4935e-8966-4136-97fe-47c79ca54635)
- 설계 이력: `docs/superpowers/specs/2026-10-06-daily-log-app-design.md`

## 개요

나날은 하루 기록만 담당하는 종이 다이어리 같은 앱이다. 불렛저널의 빠른 기록과 이월(migration)로 할 일을 놓치지 않고, 기분과 회고를 구조화해 쌓는다.

| 항목 | 내용 |
| --- | --- |
| 플랫폼 | iPhone 우선, iPad·Mac(넓은 배치) 지원. Expo(React Native) |
| 저장 | 기기 SQLite가 원본, Supabase(Postgres)와 동기화 |
| AI | 정리해서 넣기 Claude Haiku 4.5, 월간 돌아보기 Claude Sonnet 5.5 (Supabase Edge Function 경유) |
| 번들 ID | `nanal.mengle.zen` (위젯 `nanal.mengle.zen.widget`) |
| 배포 | TestFlight, 현재 빌드 10 |

**설계 원칙**

- 놓친 날에도 부담이 없다: 연속 기록(스트릭) 대신 "기록한 날 N일"처럼 줄지 않는 누적 수만 보여 준다.
- 데이터는 처음부터 구조화한다: 기분 점수, 템플릿, 할 일 상태, 밀린 사유를 필드로 저장한다.
- 기록 도구이며 치료 도구가 아니다. AI는 진단하지 않고 관찰만 한다.
- 결정은 사용자가 한다: 앱이나 AI가 할 일을 저절로 옮기거나 지우지 않는다.

**화면 구성**

1. 표지 → 오늘 장(기본 화면)
2. 오늘 장 → 하루 마무리 (주 버튼)
3. 오늘 장 → 지난 기록 (책갈피 끈): 달력 / 회고 모아보기 / 언젠가
4. 지난 기록 → 월간 돌아보기
5. 새 달 첫 실행 → 월초 정리 시트

일반 노트, 지식 정리, 문서 간 링크는 범위 밖이다(옵시디언 담당).

## 회원가입과 로그인

로그인 화면 하나가 세 장면(로그인 / 새 노트 만들기 / 메일함 확인)을 오간다. 이메일과 비밀번호만 쓰고, 가입하면 인증 메일의 링크를 눌러야 로그인할 수 있다.

**흐름**

1. **로그인**: 큰 수첩 표지 아래 이메일·비밀번호 칸과 "로그인" 버튼. 아래에 "처음이세요? 새 노트 만들기".
2. **새 노트 만들기(가입)**: "‹ 로그인" 돌아가기, 작은 수첩 머리 "새 노트 만들기 / 첫 장을 펼쳐 볼까요", 이메일, 비밀번호(8자 이상), 동의 체크, "가입하기".
3. **메일함을 확인해 주세요**: "<이메일>으로 인증 링크를 보냈어요. 링크를 누른 뒤 여기로 돌아와 로그인하면 돼요." + "메일이 안 보이면 스팸함도 봐 주세요", "로그인하러 가기", "메일 다시 보내기".
4. 메일의 인증 링크(`nanal://auth/confirmed`)로 앱이 열리면 로그인 화면에 "인증됐어요. 로그인해 주세요". 링크가 만료됐거나 이미 쓰였으면 "인증 링크가 만료됐거나 이미 쓰였어요. 로그인해 보고, 안 되면 인증 메일을 다시 받아 주세요".
5. 로그인하면 표지가 펼쳐지고, 처음이면 온보딩, 아니면 오늘 장으로 간다.

**입력 규칙**

| 항목 | 규칙 |
| --- | --- |
| 이메일 | `글자@글자.글자` 모양인지만 가볍게 본다. 진짜 확인은 인증 메일이 한다 |
| 비밀번호 | 가입은 8자 이상. iOS 비밀번호 제안에도 같은 규칙을 알려 준다 |
| 동의 | "개인정보 처리방침을 읽었고 동의해요. AI 정리나 월간 돌아보기를 쓰면 그때 적은 글과 기록이 Anthropic으로 보내져요." 체크해야 가입 버튼이 켜진다. "개인정보 처리방침"을 누르면 Notion 페이지가 열린다 |
| 가입 버튼 | 이메일 모양 + 비밀번호 8자 + 동의가 모두 맞아야 켜진다 |
| 인증 메일 다시 보내기 | 보낸 뒤 30초는 "N초 뒤에 다시 보낼 수 있어요". 성공하면 "다시 보냈어요" |

**오류 문구** (서버의 영어 문구는 그대로 보여 주지 않는다)

| 상황 | 문구 |
| --- | --- |
| 이메일·비밀번호 틀림 | 이메일이나 비밀번호가 맞지 않아요. 다시 확인해 주세요 |
| 인증 전 로그인 | 아직 이메일 인증을 하지 않았어요. 받은 메일함에서 인증 링크를 눌러 주세요 (+ "인증 메일 다시 보내기") |
| 이미 가입한 이메일 | 이미 가입한 이메일이에요. 로그인해 주세요 |
| 쉬운 비밀번호 | 비밀번호가 너무 쉬워요. 8자 이상으로 조금 더 길게 해 주세요 |
| 잘못된 이메일 | 이메일 주소를 다시 확인해 주세요 |
| 너무 잦은 시도 | 시도가 너무 잦았어요 / 메일을 너무 자주 보냈어요. 잠시 뒤에 다시 해 주세요 |
| 가입 막힘 | 지금은 가입을 받을 수 없어요. 잠시 뒤에 다시 해 주세요 |
| 오프라인 | 인터넷에 연결되지 않았어요. 연결하고 다시 해 주세요 |
| 그 밖 | 로그인하지 / 가입하지 / 메일을 보내지 못했어요. 잠시 뒤에 다시 해 주세요 |

**화면 배치**

- 아이폰: 키보드가 오르면 큰 표지가 왼쪽 위 작은 수첩으로 줄고 옆에 "나날 / 오늘도 한 줄씩"이 나타난다. 버튼은 키보드 바로 위에 폭 가득 붙고, 그동안 "새 노트 만들기" 입구는 숨는다.
- 아이패드·Mac: 표지와 양식을 가운데 한 묶음으로 둔다.
- 버튼은 처리 중에 "로그인하는 중…" / "만드는 중…"으로 바뀐다. 동의 체크는 VoiceOver 동작으로 처리방침도 열 수 있다.

로그아웃·계정 삭제는 "계정, 동기화, 데이터" 섹션에 있다.

## 온보딩

처음 여는 사람에게 책 한 권을 건네는 화면이다. 표지를 펼치면 노트 네 장이 저절로 써지고, 다 보면 오늘 장에 첫 줄을 쓰러 간다.

**흐름**

1. 책상 위에 덮인 책. 표지를 누르면 책등을 축으로 표지가 넘어가고 오른쪽 장으로 다가간다. 그 장이 첫 노트다.
2. 노트 네 장을 넘겨 본다. 장마다 글씨가 한 줄씩 써지고 그림·포스트잇이 붙는다. 한 번 본 장은 다시 써지지 않는다.
3. 마지막 장의 "첫 줄 쓰기"나 "건너뛰기"를 누르면 글씨가 흐려지며 사라지고 오늘 장이 올라온다(종이는 그대로 이어진다).

**네 장의 내용**

| 장 | 제목 | 내용 |
| --- | --- | --- |
| 1 | 나날 쓰는 법 | 오늘 날짜. 하루를 한 줄씩 적는 불렛 노트, 할 일과 메모는 기호 하나로 빠르게, 저녁엔 일기처럼 마음을 돌아본다 |
| 2 | 기호 하나로 적어요 | • 보고서 초안 / ◐ 3시 팀 회의 / ●✓ 우유 사기 / – 창가 자리 최고 / › 은행 들르기. 기호를 누르면 상태가 바뀌고, 형광펜은 하루 3개, 오른쪽 밀기는 형광펜·왼쪽 밀기는 미루기와 지우기 |
| 3 | 하루는 이렇게 | 아침: 어제 넘어온 일 고르기(그날 했으면 체크, 오늘로, 지우기) / 낮: 떠오를 때마다 한 줄씩 / 저녁: 잉크병에 기분, 회고로 마무리 |
| 4 | 마지막으로 | 책갈피 끈 = 지난 날과 회고, 한 달이 차면 월간 돌아보기, (i) = 기호 설명. "며칠 쉬어도 괜찮아요. 쌓인 날은 줄어들지 않아요." → "이제 오늘의 첫 줄을 써 볼까요" |

**조작**

- 아래 버튼: "‹ 이전 장" · "다음 장 ›"(마지막 장에서는 "첫 줄 쓰기"), 위에 "건너뛰기".
- 옆으로 50pt 넘게 밀거나 빠르게 튕기면 장을 넘긴다. 넘기는 동안 누름은 무시한다.
- VoiceOver는 한 장을 한 번에 읽는다(기호는 "점은 할 일"처럼 말로 풀고, 그림은 읽지 않는다). "4장 중 2장"처럼 위치를 알려 준다.
- 동작 줄이기: 표지에서 첫 장으로, 장과 장 사이를 흐리게만 바꾼다.

**한 번만 보인다**

- 끝내거나 건너뛰면 기기에 본 것으로 남긴다(`nanal.onboarded`). 기기마다 따로라 새 기기나 앱을 다시 설치하면 한 번 더 본다.
- 저장소를 읽지 못하면 본 것으로 친다(열 때마다 뜨지 않게).
- 온보딩 중에는 월초 정리 시트를 띄우지 않고, 위젯·컨트롤로 들어온 링크는 버린다.

## 기록 규칙

줄은 할 일과 메모 두 가지다. 일정은 따로 없고 시간을 글에 적는다(예: "15:00 팀 회의").

| 기호 | 뜻 | 상태 값 | 기호를 누르면 |
| --- | --- | --- | --- |
| • | 할 일 | `open` | 진행 중 |
| ◐ | 진행 중 | `doing` | 끝냄 |
| ●✓ + 취소선 | 끝낸 일 | `done` | 다시 할 일 |
| › (흐리게) | 옮긴 일 | `migrated` | 바뀌지 않음 |
| × + 흐린 취소선 | 안 하기로 한 일(내려놓은 일) | `dropped` | 다시 할 일 |
| – | 메모 | 없음 | 바뀌지 않음 |
| 노란 형광펜 | 중요 | `priority` | 끝나지 않은 할 일만, 하루 3개까지 |

- **하루의 경계는 새벽 4시**다. 00:00\~03:59에 적은 기록은 전날 장에 들어간다(앱·위젯 모두 `logicalDate` 한 함수로 계산).
- **옮기기는 복사다.** 원래 줄은 ›로 남고, 새 날짜에 같은 글의 줄이 생긴다. 새 줄은 `migrated_from`으로 원래 줄을 가리켜, 처음 적은 날까지 거슬러 올라갈 수 있다.
- **지우기는 숨김**이다. `deleted_at`만 찍고 행은 남는다. 모든 지우기·옮기기·안 하기에는 잠깐 "되돌리기" 토스트가 뜬다.
- "할 일 N개 중 M개" 같은 셈과 위젯에서 안 하기로 한 일은 빠진다.
- 줄 한 개는 200자까지다.

## 오늘 장

오늘 장은 공책 한 쪽이다. 왼쪽 붉은 여백선 옆에 기호, 오른쪽에 글을 쓰고, 줄은 적은 순서 그대로 놓인다. 상태를 바꾸거나 형광펜을 칠해도 줄이 움직이지 않는다.

**적기**

- 맨 위 입력칸에 한 줄을 적는다. 아래 칩으로 종류(• 할 일 / – 메모)를 고르고, (i)를 누르면 기호 설명이 뜬다.
- 입력칸 오른쪽은 마이크(말로 적기)다. 마이크를 못 쓰는 빌드(Expo Go)에서는 연필(정리해서 넣기)이다.
- 표지가 다 펼쳐진 뒤 입력칸에 한 번 포커스가 간다.

**줄을 다루는 방법**

| 손짓 | 동작 |
| --- | --- |
| 기호 누르기 | 다음 상태로 (• → ◐ → ●✓ → •) |
| 글 누르기 | 그 자리에서 고치기. 비우면 원래 글로 |
| 길게 누르기 (움직이지 않고 놓기) | ⋯ 메뉴 |
| 길게 누른 채 위아래로 끌기 | 줄 순서 바꾸기(같은 날 안에서만). 끝 가까이에서 저절로 굴러간다 |
| 오른쪽으로 밀기 | 형광펜 칠하기·지우기(끝나지 않은 할 일만). 3개면 튕겨 돌아온다 |
| 왼쪽으로 밀기 | › 미루기 · × 안 하기 · × 지우기. 줄 폭 60% 넘게 끝까지 밀면 바로 지운다 |

⋯ 메뉴에는 모든 동작(상태 바꾸기, 중요, 미루기, 고치기, 안 하기, 지우기)이 다 들어 있다. 스크린 리더는 줄의 동작 목록으로 같은 일을 한다("위로 옮기기" 포함).

**미루기**

"언제로 미룰까요?" 시트에서 내일 / 이번 주말 / 다음 주 월요일 / 날짜 고르기 중 하나를 고른다. 오늘과 지난 날은 못 고른다. 앞날로 미룬 일은 그날이 오면 그날 장에 보인다.

**지난 할 일 포스트잇**

오늘보다 앞선 날의 끝나지 않은 할 일을 포스트잇에 모아 보여 준다. 가까운 날 묶음이 위("어제 · 10월 13일(화)에 적은 일")이고, 처음에는 3줄만 보이고 나머지는 "외 N개"다.

- ○ 그날 했어요: 옮기지 않고 원래 날짜 장에 끝낸 일로 남긴다.
- 오늘 하기: 오늘 장으로 옮긴다. 여러 개면 "모두 오늘 하기".
- ×: 지운다.
- 정리한 줄은 옆으로 밀려 사라지고, 마지막 줄을 정리하면 포스트잇이 떼어지듯 사라진다.

오른쪽 위 주 버튼은 하루 마무리, 그 왼쪽에 늘어진 남색 책갈피 끈은 지난 기록이다. 계정 버튼은 제목 옆에 있다.

## 말로 적기와 정리해서 넣기

말하거나 글로 한꺼번에 적은 내용을 AI가 할 일·메모와 날짜로 나눠 주고, 사용자가 확인한 것만 장에 넣는다.

1. 마이크를 누른다. 권한을 묻고, 한국어로 계속 받아 적는다(중간 결과, 문장부호 포함). 기기 인식을 지원하면 기기만, 아니면 Apple 서버 인식을 쓴다.
2. "다 말했어요"를 누르면 받아 적은 글을 바로 정리 시트로 넘긴다.
3. **처음 한 번은 AI 사용 동의**를 받는다. "AI로 정리해도 될까요?" 패널이 아래에서 올라와 보내는 것(말하거나 적은 글, 오늘 날짜)·보내지 않는 것(이미 적어 둔 할 일, 기분, 회고, 이메일)·보낸 글은 나날 서버에 저장하지 않는다는 것을 보여 준다. "동의하고 정리하기"를 누르면 계정(user_metadata `ai_consent_at`)에 남겨 다른 기기에서도 다시 묻지 않는다. "AI 없이 메모로 남기기"는 쓴 글을 메모 한 줄로 저장한다. 동의를 저장하지 못하면(오프라인) 패널에 오류를 보이고 메모로 남기기를 고를 수 있다.
4. 서버 함수 `organize-voice`가 Claude Haiku 4.5로 `{kind, text, date}` 목록을 만든다(최대 10개).
5. "이렇게 정리했어요"에서 넣을 줄을 고르고 "N개 넣기"를 누른다.

| 규칙 | 내용 |
| --- | --- |
| 횟수 한도 | 사용자마다 하루(논리 날짜) 10번. 모델을 부르기 전에 셈다 |
| 서버 검증 | 모르는 종류·빈 글은 버리고, 지난 날·잘못된 날· 1년 넘게 먼 날은 오늘로 |
| 오프라인 | 받아 적은 글을 메모 한 줄로 저장 |
| 권한 거절·인식 실패 | "글로 적기"로 같은 정리 시트를 연다 |
| 멈춤 방지 | 받아 적기를 켜거나 멈출 때 8초 안에 답이 없으면, 받아 적은 글이 있으면 그대로 넘기고 없으면 "다시 말하기 / 글로 적기"를 보인다. 시트를 닫은 뒤 늦게 온 중단 신호는 무시한다 |
| 날짜 계산 | 서버가 오늘부터 3주치 날짜·요일 달력(오늘·내일·모레·글피 표시)을 함께 보내, 모델이 요일을 직접 세지 않고 골라 쓴다. 날짜 말은 글에서 뺀다 |
| 시간 제한 | 앱은 정리 30초, 월간 돌아보기 90초까지 기다린다. 넘으면 "잠시 뒤에 다시" 안내 |
| 개인정보 | 음성 파일은 저장하지 않고, 글은 서버에 저장하거나 로그에 남기지 않는다 |

마이크는 개발용·출시 빌드에만 있다. 잠금화면 컨트롤(말로 적기)에서도 바로 열 수 있다.

## 하루 마무리

하루 마무리는 1분 안에 끝내는 저녁 회고다. 기분과 회고 모두 건너뛸 수 있다.

- **기분**: 잉크병 다섯 개 중 하나를 고른다(1\~5). 고른 병에 잉크가 차오르고 깃펜이 꽂힌다. 비워 둘 수 있다.
- **회고 템플릿**: 칩에서 하나를 고르고 줄 노트 카드에 답한다.

| 템플릿 | 질문 |
| --- | --- |
| 무기력했던 날 | 무기력의 원인으로 짐작되는 것은? / 오늘을 회복의 시간으로 본다면 무엇을 채웠나? |
| 감사한 날 | 오늘 좋았던 일 3가지와 그 이유 |
| 자유 일지 | 자유롭게 쓰기 |
| 내가 만든 템플릿 | 이름 + 질문 1\~3개 |

- "+ 새 템플릿"에서 이름과 질문을 적고 저장하면 그 템플릿이 바로 고르어진다.
- 내가 만든 칩을 길게 누르면 수정하기 / 삭제하기. 기본 템플릿은 바꿀 수 없다.
- 회고를 저장할 때 템플릿 이름과 질문을 함께 남긴다. 템플릿을 고치거나 지워도 지난 회고는 그대로 읽힌다.
- 배경은 저녁 종이색이다. "닫기"를 누르면 오늘 장으로 돌아간다.

## 지난 기록

지난 기록은 책갈피 끈을 눌러 열고, 달력 / 회고 모아보기 / 언젠가 세 탭으로 나뉜다.

**달력**

- 날짜마다 그날 기분의 잉크병과 회고 점이 보인다. 달을 넘겨 볼 수 있다.
- 날짜를 누르면 그날 할 일·메모, 기분, 회고를 본다. 요약에 "할 일 N개 중 M개"와 "N개는 안 하기로 했어요"가 나온다.
- 끝나지 않은 할 일이 있는 앞날은 숫자 아래 작은 ›로 표시하고, 누르면 "이날 할 일"을 본다. 가장 먼 앞날이 있는 달까지 넘길 수 있다.
- 매달 1일 이후 위쪽에 "<지난달> 돌아보기 만들기" 배너가 뜬다. 이번 달에 넘어온 일이 남아 있으면 "지난달 정리하기" 링크도 뜬다.

**회고 모아보기**

쓴 회고를 모아 보고, 템플릿으로 걸러 볼 수 있다.

**언젠가**

날짜 없는 할 일을 모아 두는 목록 하나다. "N줄 · M개 끝냄"을 보여 준다.

- 맨 위 칸에 한 줄을 더한다(할 일만). 기호는 • ↔ ✓이고 진행 중은 없다. 끝낸 줄은 아래로 모인다.
- 오른쪽 밀기는 형광펜(개수 제한 없음), 왼쪽 밀기는 오늘 할 일로 · 지우기다. 끝내지 않은 줄끼리 끌어서 순서를 바꾼다.
- "오늘 할 일로"는 오늘 장에 같은 글의 할 일을 만들고, 언젠가 줄은 ›로 흐리게 남긴다.
- 언젠가 줄은 포스트잇·월초 정리·위젯·월간 돌아보기에 섞이지 않는다.
- 빈 목록 문구: "생각나면 적어 두세요. 매일 고르라고 하지 않아요".

## 월초 정리와 월간 돌아보기

새 달 첫 실행에 지난달까지 끝나지 않은 할 일을 한 장에서 정리하고, 원하면 AI가 지난달을 돌아본다.

**월초 정리 시트 ("<이번 달> 첫 장")**

- 새 달(새벽 4시 기준) 첫 실행에 표지가 다 펼쳐진 뒤 한 번 뜬다. 이번 달 1일보다 앞선 끝나지 않은 할 일이 없으면 뜨지 않는다.
- 따져 본 달은 기기에 남겨 같은 달에 두 번 뜨지 않는다. 온보딩 중이거나 위젯 동작을 처리하는 중에는 뜨지 않는다.
- **오래 머문 일**: 처음 적은 달부터 두 달 이상 지난 일을 맨 위 카드에 따로 모은다. 몇 번 옮겼는지가 아니라 `migrated_from`을 거슬러 찾은 처음 적은 날로 셈다. "석 달째 넘어온 일"처럼 기간을 붙이고 오래된 일이 위다.
- **밀린 사유 칩**(오래 머문 일에만): 일이 너무 커서 / 마음이 안 가서 / 먼저 풀 일이 있어서 / 기운이 없어서 / 부담스러워서. 고르지 않아도 되고, 같은 칩을 다시 누르면 풀린다. 고른 사유는 옮기거나 내려놓는 원래 줄의 `delay_reason`에 남고, 되돌리면 지워진다.
- **처음 넘어온 일**: 원래 날짜별로(오래된 날부터) 묶어 보여 준다. 여러 개면 "모두 이번 달로"가 있고, 이 버튼은 오래 머문 일을 옮기지 않는다.
- 줄마다 ○ 그날 했어요 / 이번 달로(오늘 장으로 옮기기) / 내려놓기(지우지 않고 줄을 그어 남김, "내려놨어요 · 되돌리기").
- "나중에"는 닫기만 한다(오늘 포스트잇에 그대로 남는다). 다 정리하면 "새 달을 시작해요"를 남기고 잠시 뒤 닫힌다.
- 목록 아래에 "<지난달> 돌아보기 만들기/보기" 카드가 있다.

**월간 돌아보기 (AI)**

| 항목 | 내용 |
| --- | --- |
| 만드는 법 | 사용자가 버튼을 눌러야 만든다(자동 생성 없음) |
| 조건 | 그 달 기록한 날이 7일 이상. 모자라면 "기록이 조금 더 쌓이면 볼 수 있어요" |
| 보내는 것 | 기분 점수, 회고 질문과 답변, 할 일의 종류·상태·개수. **할 일 글은 보내지 않는다**. 결과는 내 계정의 기록에 저장된다 |
| 모델 | Claude Sonnet 5.5. 숫자는 서버 함수가 계산하고 AI는 글만 쓴다 |
| 결과 | 한 달의 잉크(달력), 기분의 흐름, 무기력했던 날, 할 일과 마음, 자주 고마웠던 것, 다음 달에 해 볼 한 가지 |
| 말투 | 판단·진단 없이 관찰만. "진단이 아니다" 안내와 자살예방상담전화 109(누르면 전화) 안내를 함께 보여 준다 |
| 한도 | 대상 달마다 1번. 이미 만든 달은 "이 달 돌아보기는 이미 만들었어요. 돌아보기는 한 달에 한 번 만들 수 있어요"만 보여 준다 |

밀린 사유는 아직 월간 돌아보기에 들어가지 않는다. 사유가 한두 달 쌓인 뒤 붙일 계획이다.

## 위젯과 컨트롤

위젯은 앱과 같은 DB 파일(App Group 공유 폴더)을 읽고, 상태 버튼으로 할 일을 바로 바꿀 수 있다. 글 입력과 녹음은 iOS가 막아서 앱을 연다.

| 자리 | 크기 | 보여 주는 것 |
| --- | --- | --- |
| 홈 화면 | 작은 | 오늘 기분, 기록한 날 |
| 홈 화면 | 중간 | 오늘 할 일 3개 + 상태 버튼 |
| 홈 화면 | 큰 | 상태 칩(밀린 일 / 할 일 / 진행 중 / 한 일), 누르면 다음 상태 |
| 잠금화면 | 직사각형 | 다음 할 일 + 상태 버튼 (글은 가려지는 개인정보로 표시) |
| 잠금화면 | 원형 | 남은 수, 오늘 기분 |
| 컨트롤 (iOS 18+) | 버튼 | 말로 적기(`nanal://voice`), 한 줄 적기(`nanal://today?focus=1`) |

- "다음 할 일"은 진행 중 → 형광펜(중요) → 오늘 목록 순서로 고른다. 밀린 일은 개수로만 보여 준다.
- 상태 버튼은 앱의 기호 누르기와 같이 한 단계씩 바꾼다. 위젯에 보이던 상태일 때만 바꾸고, 바꾼 것은 outbox에 남아 앱이 열릴 때 동기화된다.
- 앱이 화면을 다시 그릴 때마다, 그리고 30분마다·새벽 4시에 위젯이 새로 고쳐진다.
- 공유 폴더가 없으면 위젯은 "앱을 한 번 열어 주세요"를 보여 준다.

## 계정, 동기화, 데이터

모든 읽기와 쓰기는 기기에서 하고, 네트워크가 되면 뒤에서 서버와 맞춘다. 화면은 네트워크를 기다리지 않는다.

**계정**

- 이메일과 비밀번호로 가입·로그인한다. 가입할 때 개인정보 처리 동의가 필요하다. 세션은 기기 보안 저장소에 둔다.
- 계정 시트(아이패드·Mac은 사이드바)에 이메일, 로그아웃, 그리고 아래 작은 링크 한 줄 "개인정보 처리방침 · 문의하기 · 계정 삭제"가 있다. 처리방침은 Notion 페이지, 문의하기는 메일 앱을 연다(열지 못하면 이메일 주소를 보여 준다).
- 계정 삭제는 확인 창(시트가 다 내려간 뒤) → "삭제하는 중…" 표시 → 서버 함수 `delete-account`(20초 넘게 답이 없으면 실패 안내) → 이 기기 기록 비우기 → 로그아웃 순서다. 서버 데이터는 모두 함께 지워진다.
- 이 기기에 다른 계정의 기록이 있으면 앱을 막고 "그 계정으로 다시 로그인해 주세요"를 보여 준다.

**동기화**

1. 쓸 때마다 같은 트랜잭션에서 바뀐 줄을 outbox(보낼 목록)에 적는다.
2. 올리기(push): outbox의 줄을 서버에 upsert하고, 성공한 것만 지운다. 실패하면 남겨 두고 다시 보낸다.
3. 받기(pull): 마지막으로 받은 뒤 바뀐 줄을 받아 반영한다.
4. 같은 줄이 충돌하면 `updated_at`이 더 최신인 쪽이 이긴다(LWW).

- 동기화 시점: 앱 시작, 앱이 앞으로 돌아올 때, 쓴 직후(짧은 지연). 아직 못 올린 것이 있으면 "아직 올리지 못했어요"를 보여 준다.
- 서버가 모르는 열이 있으면 그 표만 올라가지 못하고 outbox에 남는다. 데이터는 잃지 않는다. 그래서 **서버 마이그레이션을 앱 배포보다 먼저 적용한다.**

**표**

| 표 | 담는 것 |
| --- | --- |
| `items` | 오늘 장의 줄: 날짜, 종류, 글, 상태, 중요, `migrated_from`, `delay_reason`, `position` |
| `days` | 날짜별 기분(1\~5) |
| `reflections` | 회고 답변 + 템플릿 스냅샷 |
| `templates` | 내가 만든 회고 템플릿 |
| `someday` | 언젠가 목록 |
| `monthly_reviews` | 월간 돌아보기 결과(달마다 하나) |
| `ai_usage`, `ai_entitlements` | AI 호출 횟수와 유료 이용권(서버에만) |

- 모든 표에 RLS를 켜 로그인한 사용자 자기 줄만 읽고 쓸 수 있다. 로그인하지 않은 요청은 `42501`로 막힌다.
- 앱에는 anon key만 넣는다. Anthropic API 키는 Edge Function Secret에만 둔다.
- 기기 DB는 위젯과 함께 쓰기 위해 App Group 공유 폴더에 있다.

## 화면 크기, 접근성, 표지

아이폰은 화면을 밀어 넣는 스택으로, 아이패드·Mac은 왼쪽 사이드바로 화면을 바꾼다.

**화면 크기**

- 아이패드·Mac: 사이드바에서 오늘 / 하루 마무리 / 지난 기록 / 계정. 사이드바는 접고 펼 수 있고(미끄러지며 본문이 넓어짐) 접은 상태를 기기에 기억한다.
- 본문은 읽기 폭으로 가운데에 모은다. 넓은 배치에서는 글자 눈금도 함께 커진다.
- 키보드가 올라오면 화면 높이가 그만큼 줄어 내용을 덮지 않는다.

**접근성**

- 누르는 영역은 44pt 이상. 작은 글씨는 종이 대비 4.5:1 이상의 색만 쓴다.
- 큰 글자 설정을 따른다. 버튼은 잘리지 않고 다음 줄로 내려간다.
- VoiceOver: 모든 밀기·끌기 동작을 줄의 동작 목록으로도 할 수 있다. 정리가 끝나면 소리로 알려 준다.
- 동작 줄이기: 표지는 흐리게만 바뀌고, 들림·튕김·밀려 사라지기 애니메이션을 뺀다. 동작 자체는 그대로 된다.

**표지**

- 앱을 열면 하드커버 표지가 펼쳐진다. 그날 첫 실행만 넘기는 모션이고, 같은 날 다시 열면 짧게 흐려지며 열린다.
- 표지가 다 펼쳐진 뒤에야 입력칸 포커스, 월초 정리 시트, 위젯 링크 동작이 일어난다. 온보딩은 위 "온보딩" 섹션에 있다.
